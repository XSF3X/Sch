# نظام حجز الجداول للمعلمين

## الفكرة
كل معلم يدخل صفحة خاصة به، يرى الإسنادات والحصص المطلوبة، ويحجز الخانات المتاحة. النظام يمنع حجز الخانة نفسها مرتين، ويمنع تجاوز نصاب المعلم أو نصاب المقرر. بعد اكتمال الحجز يمكن للإدارة إغلاقه وتشغيل محرك إكمال/تحسين الجدول.

## الحالة الحالية
- `index.html`: اختيار المعلم.
- `teacher.html`: صفحة الحجز الفردية.
- `admin.html`: لوحة متابعة مبدئية.
- `data.js`: بيانات المعلمين والإسنادات المستخرجة من جدول المدرسة الحالي.
- `supabase-schema.sql`: مخطط قاعدة البيانات المشتركة.
- `config.example.js`: قالب إعداد Supabase.

النسخة الحالية تعمل بوضع تجريبي محلي باستخدام `localStorage` حتى يمكن اختبار الواجهة فورًا على GitHub Pages. لكي تصبح الحجوزات مشتركة بين جميع المعلمين نضع إعدادات Supabase ونربط عمليات القراءة/الحجز بالـ API.

## القواعد الخاصة
قرناس المطيري: الأربعاء يوم ذهبي، والخميس الأولى والسابعة فقط. هذه القاعدة ستنقل أيضًا إلى طبقة قاعدة البيانات في النسخة المشتركة.

## النشر
المشروع موجود في فرع `teacher-booking-v1` من مستودع `XSF3X/Sch`. يمكن تفعيل GitHub Pages على هذا الفرع/المسار، أو دمج المجلد في `main` لاحقًا.
